# Research project website

A minimal anonymous academic project page containing the paper title, teaser image, and abstract. Built with local HTML and CSS, without scripts, external fonts, analytics, or dependencies.

## Edit

Update the title and abstract in `index.html`. Adjust the layout in `style.css`. The teaser is hosted locally at `assets/teaser.png`; click it on the page to view the full-resolution image. The image contains no textual or EXIF metadata.

## Preview

Run `python3 -m http.server 8000`, then open http://localhost:8000.

## Deploy

In GitHub Pages settings, select **Deploy from a branch**, **main**, and **/ (root)**.
